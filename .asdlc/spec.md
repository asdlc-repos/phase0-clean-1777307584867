# Overview

A basic web application that displays a "Hello World" message when someone visits it.

# Personas

- Visitor — views the greeting message.

# Features

- A visitor opens the application in their web browser.
- The page displays "Hello World" as the main content.
- The message appears immediately when the page loads.
- The page has a simple, readable layout.
- Visitors can refresh the page to see the message again.
